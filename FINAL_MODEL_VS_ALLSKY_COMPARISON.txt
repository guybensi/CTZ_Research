================================================================================
3. COMPARISON
================================================================================
- guy_model.py's ANN (RMSE=5.76 W/m^2) outperforms All_Sky_AIflux.py's ANN
  (RMSE=17.72 W/m^2) by roughly 3x lower error.
- guy_model.py's classical Ridge baseline alone (RMSE=11.03 W/m^2) also beats
  All_Sky_AIflux.py's ANN.
- Likely contributors to the gap:
  1. Feature selection: guy_model.py uses 20 features chosen by Random Forest
     importance ranking out of the full 129-feature moments+scalars set (includes
     cloud fraction, cloud top height, AOD, lat/lon, etc.). All_Sky_AIflux.py
     uses a fixed, smaller, hand-picked 37-feature set of geometry + spectral
     mean/skew only, with no cloud/aerosol/geolocation scalars.
  2. Network capacity: guy_model.py's ANN has two hidden layers (10, 5 units)
     vs. All_Sky_AIflux.py's single hidden layer (18 units).
  3. Train/test split: 80/20 vs 70/30.
- Both scripts were run unmodified (original regression logic preserved per
  project rules); this comparison reflects the existing pipelines as-is, not a
  tuned apples-to-apples experiment.
